GitHub connection

How to get a key (one time, about 3 minutes)
  1. Sign in to GitHub and open github.com/settings/personal-access-tokens/new.
  2. Name it something like “PATROLscroller admin” and pick an expiration (one year is fine).
  3. Under Repository access, choose Only select repositories and pick BLET2026.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

The key is stored on this device only, locked with your admin password. Anyone with the key can change your site, so don’t share it.

Practice test

On The 300-question practice exam in Games. When it’s off, students see it as “not open yet.” It always uses only the lessons that are open.

Lessons

Switch a lesson on to open it now, or set a date for it to open by itself that morning. Students see changes a few minutes after you save.

A lesson that’s switched on is fully unlocked. A lesson with a future date stays hidden in the app until that date, but its key is in the settings file early, so a determined, tech-savvy student could open it ahead of time. For a hard lock, leave the date blank and switch it on when you get there.
